# Cloudflare 正式部署指南

本项目运行在Cloudflare Workers上：D1保存作品、管理员凭证和记录，Workers KV保存分片媒体。首次部署可以直接使用免费的`workers.dev`地址。

## 推荐流程：部署按钮

1. 打开[Deploy to Cloudflare](https://deploy.workers.cloudflare.com/?url=https://github.com/q1433031046-ship-it/student-portfolio-cloudflare)。
2. 登录Cloudflare并确认官方授权。
3. 保持`DB`和`MEDIA_KV`为“Create new”。
4. 在`INITIAL_ADMIN_CODE`中输入自己设置的至少16位、同时包含英文字母和数字的口令。只在Cloudflare页面输入。
5. 点击Deploy，等待数据库迁移和Worker发布完成。
6. 打开生成的`workers.dev`地址；空白站点会引导进入`/admin`。
7. 输入同一段一次性部署口令，创建10至128位、同时含文字和数字的管理员密码。
8. 下载系统恢复码并离线保存，然后进入后台。

## 登录与找回

- 日常登录只输入管理员密码。
- 登录连续失败5次后，后台锁定15分钟。
- 管理会话有效期12小时；“安全退出”会立即撤销当前会话。
- 忘记密码时选择“使用系统恢复码”，输入新密码。
- 找回成功会撤销所有旧会话，使旧恢复码失效，并显示一份新恢复码。
- 密码和最新恢复码同时丢失时，需要让部署代理在D1中执行管理员凭证重置；系统不会保留可读密码或可读恢复码。

## 网站空间

后台`概览`页面最下方显示：

- 已使用空间；
- 剩余空间；
- 媒体文件总数；
- 大约还能放多少个50 MB视频。

应用容量上限为800 MiB，达到700 MiB时提示预警，达到800 MiB后拒绝新上传。这个上限会为账户级KV容量保留余量；同一Cloudflare账户下其他项目的KV用量也要计入[Cloudflare KV限制](https://developers.cloudflare.com/kv/platform/limits/)。

## 视频上传与播放

- 上传MP4，推荐H.264视频和AAC音频，单个文件不超过50 MB。
- 浏览器按4 MiB分片上传；失败分片最多重试3次。
- 服务端检查首片的MP4文件标识。
- 播放接口支持单段HTTP Range；浏览器可以拖动进度条，服务端只读取所需分片。
- 一个50 MB视频最多13个分片。10个人完整观看约产生130次分片读取和500 MB媒体传输，低于免费账户每日100,000次KV读取和100,000次Worker请求的数量级限制。实际请求数会因浏览器预读、重复拖动和缓存变化而增加。[KV限制](https://developers.cloudflare.com/kv/platform/limits/) · [Workers限制](https://developers.cloudflare.com/workers/platform/limits/)

## 大陆网络测试

正式给客户前，必须用目标客户实际使用的中国大陆移动网络和宽带各测试一次：

1. 首页能否稳定打开；
2. 50 MB视频能否开始播放；
3. 拖到25%、50%、75%位置能否继续；
4. 10台设备同时播放时是否频繁缓冲。

程序和免费配额足以承载10个人今天完整观看一次；`workers.dev`在不同大陆运营商的线路质量不完全一致，因此最终流畅度以现场网络测试为准。若现场线路不稳定，应先使用更低码率的视频，并为正式商业使用准备面向大陆网络的托管地址。

## 直接命令部署

部署代理可以在项目目录运行：

```bash
npm ci
npm run cloudflare:setup
```

脚本会在隐藏输入中读取一次性部署口令，构建项目、部署资源、应用D1迁移并保存Secret。后续代码更新运行：

```bash
npm run cloudflare:deploy
```

更新不会清空D1内容或`MEDIA_KV`媒体。

## 部署后检查

1. 首次后台初始化、恢复码下载、退出和密码登录。
2. 错误部署口令被拒绝；初始化完成后部署口令不能作为日常密码。
3. 用恢复码修改密码；确认旧密码、旧会话和旧恢复码失效。
4. 上传图片和接近50 MB的MP4；查看概览底部空间变化。
5. 播放视频并拖动进度条。
6. 保存草稿并快速预览；确认公开页不变。
7. 发布后确认公开页更新。
8. 测试二维码公开、限制、次数用尽和过期状态。
9. 用10台设备或10个独立浏览器会话完整播放测试视频。

## 运行资源

| 名称 | 类型 | 用途 |
| --- | --- | --- |
| `DB` | D1 binding | 作品、密码校验值、恢复校验值、会话、二维码和记录 |
| `MEDIA_KV` | KV binding | 图片、字体和MP4分片 |
| `AUTH_PLATFORM` | Worker variable | 正式部署固定为`password` |
| `INITIAL_ADMIN_CODE` | secret | 首次管理员初始化和运行密钥派生；至少16位并包含英文字母和数字 |
