# v1.3.0 手机适配候选审计交接

## 审计边界

- 基线：`v1.2.1` / `7f6d217c88414c8df5e141600bc03116af5473b5`
- 候选分支：`release/v1.3.0`
- 可信发布门禁提交位于候选历史中；审计前不要合并、创建标签或部署。
- 本轮只改响应式渲染、手机后台交互、教程、测试和发布门禁。
- 文档 schema 保持 5；数据库迁移仍止于 `0007_legacy_media_and_access_state.sql`。
- Worker 配置仍只有一个 `DB` 和一个 `MEDIA_KV`，没有新 R2 绑定；不得替换正式资源 ID。

## 重点审计

1. 前台在 320、360、390 px 宽度下无整页水平滚动；首图横向吸附，项目正文单列，联系、播放器和封底遵守安全区。
2. 手机后台只有一条底部操作栏；栏目导航、“更多”、保存状态、错误定位和 10 个作品的选择器可用。
3. 手机快速预览复用当前草稿的真实 `PortfolioExperience` 树，不使用 iframe，不保存手机专用坐标、裁切或文档字段。
4. 手机全屏裁切支持拖动、双指缩放、加减缩放、重置、取消恢复和确认写入；指针取消与丢失捕获均清理状态。
5. 上传进行中阻止切换栏目、预览、保存和发布；失败后解除阻止并保留重试、关闭与定位入口。
6. 中文输入、输入法编辑、可选空字段、可读错误信息及独立技术路径仍正常；用户界面统一使用“封底”。
7. H.264 Baseline / AAC-LC 固定样例必须分别在品牌 Chrome 和 macOS WebKit 中加载并实际推进播放时间。

## 已完成的本地门禁

```text
npm ci
npm audit --omit=dev --audit-level=high
bash -n scripts/*.sh
node --check scripts/*.mjs
npm run db:generate
npm test
npx --no-install wrangler deploy --dry-run --keep-vars --config wrangler.jsonc
npm run lint
npx tsc --noEmit
git diff --check
npx playwright test --list
```

生产构建和 194 项 Node 测试通过；Wrangler dry-run 只显示 `DB`、`MEDIA_KV`、静态资源和既有运行变量。

## 审计环境必须补跑

本地环境无法从 Playwright 官方 CDN 下载浏览器，云浏览器也不能访问隔离工作区的 `localhost`，因此以下真实浏览器结果尚未取得，不能标记为通过：

```text
npm run test:e2e
npm run test:e2e:codec:chrome
npm run test:e2e:codec:webkit
```

发布工作流已经把手机 Chromium、品牌 Chrome 编码检查和独立 macOS WebKit 编码检查设为创建标签前的硬门禁。审计必须先取得这三项证据，再决定是否允许后续远程分支、PR、合并、标签和生产升级。

## 审计后仍需所有者现场确认

- iPhone Safari 与 Android Chrome 的真实触摸、软键盘和安全区。
- 真实图片裁切、接近 50 MiB 的 H.264/AAC MP4 分片上传、Range 播放与拖动。
- 大陆手机流量和常用宽带访问。
- 正式升级前后的 Worker、workers.dev、D1、MEDIA_KV、Secrets、运行变量与数据指纹完全一致。
